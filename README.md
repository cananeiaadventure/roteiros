
CANANÉIA ADVENTURE — ARQUIVOS DO SITE
======================================

COMO SUBIR NO GITHUB
- Suba o index.html e a pasta img inteira, com os arquivos dentro dela.
- NÃO renomeie nenhum arquivo. A página procura cada um pelo nome exato.
- Se precisar trocar só um vídeo ou foto: suba o novo DENTRO da pasta img,
  com o MESMO nome do antigo, e ele substitui.
- Tamanho total: cerca de 27 MB (o GitHub aceita até 100 MB por arquivo e 1 GB por site).
